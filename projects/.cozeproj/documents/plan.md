# 计划文档：饭团小精灵 · 好好吃饭养成网站

## 概述

一个面向「吃饭不规律人群」的**日式治愈系虚拟宠物养成网站（web）**。核心闭环：用户输入自己真实吃的饭菜名称 → 宠物（一只原创"饭团小精灵"）进食、在随机区间内获得生长值、随累计餐数**进化形态**、体重随近期吃饭情况升降；用"我不按时吃，它就会饿"的情感牵挂反向督促用户规律就餐。辅以简短的 AI 对话（宠物有性格/记忆/会催饭）。集成能力：**大模型（LLM）技能**用于 AI 对话；宠物立绘由 AI 生图技能整套生成。V1 不做登录、不做社交。

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | Next.js 16 (App Router) + React 19 + TypeScript 5 | 全栈一体，需 API Route 承载 LLM 流式对话 |
| 样式 | Tailwind CSS v4 + shadcn/ui 风格 | 规范内默认，快速搭治愈系界面 |
| 数据持久化 | 浏览器 localStorage（无登录） | 单用户本地养成，零后端依赖、上线最快；后续可平滑升级 Supabase |
| 养成数值 | 前端纯规则计算 + localStorage | 生长值随机、体重/阶段/连续天数均为确定性规则，无需数据库 |
| AI 对话 | LLM 技能 + Next.js API Route，**SSE 流式**输出 | 平台内置模型，无需用户提供 API-Key；遵循流式优先，回复简短 |
| 宠物立绘 | AI 生图技能整套生成（透明 PNG，日式手绘治愈风） | 用户后续自行替换；V1 每阶段 1 张正面立绘 |
| 提醒 | 页面内状态提示 + 浏览器 Notification（可选授权） | V1 轻量实现，不做服务端推送 |

## 功能模块

### 1. 宠物状态引擎（核心，纯前端 + localStorage）
- **实体 Pet**：`{ id, name, stage: 0|1|2|3, growthValue, weight, createdAt, lastFedAt, status: 'happy'|'content'|'hungry'|'weak' }`
- **阶段 stage**：0=饭团蛋(初生) / 1=幼年小饭团 / 2=少年饭团精 / 3=成年饭团精灵；每阶段对应一张立绘。
- **进化规则**：累计有效餐数达到阈值（如 5 / 20 / 50 餐）→ stage+1，触发形态变换动画。阈值做成常量便于调参。
- **生长值**：每次喂饭在区间内随机增加（如 `+8 ~ +15`），累计推进进化进度条。
- **体重**：正常吃饭累计 → 体重在基准上缓慢上升至健康区间；长时间未进食 → 体重下降。用"距上次喂饭时长"驱动（如 >4h 开始缓慢掉，>12h 明显掉），**只影响数值与状态表情，无死亡/永久惩罚**。
- **饥饿状态**：由距上次喂饭时长 + 体重映射到 happy/content/hungry/weak，驱动立绘表情与提示文案。
- **连续打卡 streak**：按自然日，当天在"三餐时间窗"内各记录至少 1 餐即算达标，连续达标天数 +1；断一天清零（仅展示，不惩罚宠物）。

### 2. 喂饭记录（吃饭日记）
- **实体 Meal**：`{ id, foodName, fedAt, growthGain }`
- 用户在主页输入饭菜名称（任意文本，不评判营养）→ 判定宠物吃过这一餐 → 随机生长值 → 追加一条 Meal 记录。
- 时间线页按时间倒序展示每餐：饭菜名 + 时间 + 本次成长值。

### 3. 数据面板
- 展示：体重曲线（近 N 天）、连续按时吃饭天数、累计餐数、当前阶段/进化进度、进化图鉴（4 阶段立绘，未解锁置灰）。

### 4. AI 陪伴对话（轻量，流式，回复简短）
- 实体 Message：`{ role: 'user'|'pet', content, at }`（localStorage 保存最近 N 轮作为记忆）。
- API Route `/api/chat`：聚合宠物当前状态（stage、体重、饥饿状态、最近一餐饭名与时间、streak）+ 近期对话记忆，构造 system prompt（饭团小精灵人设：软萌、黏人、会催饭、会记得你最近吃了什么；**回复≤2句话、口语化**），经 LLM 技能 SSE 流式返回，前端打字机渲染。
- 冷启动/无输入时宠物会主动根据状态说话（如饥饿时"你……是不是还没吃饭呀？"）。

### 5. 提醒/打卡（轻量）
- 主页根据当前时间与三餐时间窗（早 6-9、午 11-14、晚 17-20）提示"该吃早饭/午饭/晚饭啦"；当前餐窗已记录则显示已打卡。
- 可选请求浏览器 Notification 授权，到饭点本地通知（V1 可仅做页内提示，通知作为增强）。

### 6. 宠物立绘资源
- AI 生图生成 4 张统一日式手绘治愈风、透明背景、正面、同一只饭团小精灵的进化立绘（蛋→幼年→少年→成年），存 `public/pet/stage-0..3.png`；另可生成 1 张开心/饥饿表情差异或用 CSS/小动效区分。代码中用 `/pet/stage-x.png` 引用，便于用户替换。

## 是否有原型设计

**是**。已开启设计引导，开发前先用 design-canvas 技能产出高保真 HTML 原型，经用户确认后再进入代码开发。

## 实施步骤

**阶段一：原型设计**

1. **加载 design-canvas 技能并产出高保真原型**：日式手绘治愈风，确定配色/字体/圆角/阴影等设计变量；覆盖 4 个页面（宠物主页、数据面板、吃饭日记、AI 陪伴），含饭团小精灵主视觉占位、喂饭输入框、成长进度/体重/饥饿状态、时间线、聊天气泡、饭点提醒条。完成后提示用户验收，调用 done 提交等候确认。

**阶段二：代码开发**

2. **初始化项目与设计变量迁移**：`coze init` Next.js 模板；将原型 `@theme` 设计变量完整迁移到 `globals.css`（含 shadcn 变量名映射），搭好全局布局与顶部导航。涉及 `src/app/globals.css`、`src/app/layout.tsx`。
3. **宠物立绘与素材生成**：用 AI 生图技能整套生成 4 阶段饭团小精灵立绘（透明 PNG、日式手绘、统一画风）存入 `public/pet/`。涉及 `public/pet/stage-0..3.png`。
4. **养成状态引擎与本地存储**：实现 Pet/Meal 数据模型、localStorage 读写、生长值随机、体重随时间升降、饥饿状态、阶段进化、连续打卡等纯规则逻辑（封装为 hook + 工具函数）。涉及 `src/lib/pet-engine.ts`、`src/hooks/use-pet.ts`。
5. **核心页面开发**：宠物主页（立绘+状态+喂饭输入+饭点提醒）、数据面板（体重曲线/streak/餐数/进化图鉴）、吃饭日记时间线。涉及 `src/app/page.tsx`、`src/app/stats/page.tsx`、`src/app/diary/page.tsx`。
6. **AI 陪伴对话（流式）**：`/api/chat` 路由接入 LLM 技能（SSE 流式、简短人设、注入宠物状态与近期记忆），前端聊天页打字机渲染并本地保存对话。涉及 `src/app/api/chat/route.ts`、`src/app/chat/page.tsx`。
7. **验证与交付**：通过 test_run 做静态检查 + 接口冒烟（重点 `/api/chat` 流式），核对立绘/页面与原型一致性，检查日志无异常。涉及 `test_run`。

## 页面规格

##### @nav(web-topbar)
> type: topbar
> platform: web

- @page(/) 首页
- @page(/stats) 成长
- @page(/diary) 日记
- @page(/chat) 陪伴

##### @page(/) 宠物主页

**核心职责**：展示饭团小精灵当前形象与状态，让用户"喂饭"并一眼看到它好不好。
**访问路径**：顶部导航 Logo / 首页直达。
**布局**：顶部导航栏；主区为治愈系场景卡片——中央宠物立绘（随 stage 切换、随 status 有表情/微动效）+ 名字与阶段标签；立绘下方为状态条（体重、饥饿状态、进化进度条）；底部为喂饭输入框 + "喂给它"按钮；场景顶部一条饭点提醒条（到餐窗提示，已打卡则显示鼓励）。
**状态**：
- 空态/首次：展示一颗饭团蛋，引导"输入你吃的第一顿饭，叫醒它"。
- 饥饿态：小精灵蔫蔫表情 + 温柔催饭文案。
- 加载态：立绘淡入。

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| Logo | 点击 | 跳转 @page(/) | — | — |
| 喂饭输入框 | 输入饭菜名 | 启用"喂给它"按钮 | foodName | 任意文本 |
| 喂给它按钮 | 点击 | 判定进食：随机生长值、体重回升、追加 Meal、刷新状态/进度；触发开心反馈 | foodName | 空输入时禁用 |
| 进化达成 | 自动 | 播放形态变换动画并切换立绘 | — | 达到餐数阈值 |
| 饭点提醒条 | 点击 | 聚焦喂饭输入框 | — | 餐窗内未打卡时显示 |
| 成长导航 | 点击 | 跳转 @page(/stats) | — | — |
| 日记导航 | 点击 | 跳转 @page(/diary) | — | — |
| 陪伴导航 | 点击 | 跳转 @page(/chat) | — | — |

##### @page(/stats) 成长数据面板

**核心职责**：用数据可视化呈现养成成果与吃饭规律。
**访问路径**：顶部导航"成长"直达。
**布局**：顶部导航；下方卡片网格——体重曲线图（近 N 天）、连续按时吃饭天数、累计餐数、当前阶段与进化进度；底部进化图鉴（4 张立绘，已解锁彩色、未解锁置灰剪影）。
**状态**：
- 空态：无记录时图表区显示"还没有数据，先去喂它吃第一顿吧"。

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| Logo | 点击 | 跳转 @page(/) | — | — |
| 图鉴立绘(已解锁) | 点击/悬停 | 显示该阶段名称与达成餐数 | stage | — |
| 图鉴立绘(未解锁) | 点击/悬停 | 显示"还差 N 餐解锁" | stage | 置灰 |
| 顶部导航项 | 点击 | 跳转对应页 | — | 首页/日记/陪伴 |

##### @page(/diary) 吃饭日记

**核心职责**：按时间回顾每一餐与宠物成长节点。
**访问路径**：顶部导航"日记"直达。
**布局**：顶部导航；时间线列表，倒序分组（按日期）。
**列表项字段**：饭菜名 / 喂饭时间 / 本次成长值；进化节点以特殊卡片插入时间线。
**状态**：
- 空态："还没有喂饭记录"。

**交互说明**

| 元素 | 动作 | 响应 | 传参 | 备注 |
|------|------|------|------|------|
| Logo | 点击 | 跳转 @page(/) | — | — |
| 日记条目 | 点击 | 无跳转，悬停高亮 | meal_id | 纯展示 |
| 去喂饭按钮(空态) | 点击 | 跳转 @page(/) | — | 仅空态显示 |
| 顶部导航项 | 点击 | 跳转对应页 | — | 首页/成长/陪伴 |

##### @page(/chat) AI 陪伴

**核心职责**：与饭团小精灵简短聊天，它结合状态/记忆催饭、回应。
**访问路径**：顶部导航"陪伴"直达。
**布局**：顶部导航；对话气泡区（宠物气泡左、用户气泡右，宠物带头像=当前 stage 立绘）；底部输入框 + 发送按钮；饥饿时顶部可有宠物主动冒泡。
**状态**：
- 空态：宠物先主动打招呼/根据当前状态说话。
- 加载态：流式输出时宠物气泡内打字机逐字显示 + 输入禁用。

| 元素 | 动作 | 响应 | 传参 | 备注 |

| 输入框 | 输入消息 | 启用发送 | content | — |
| 发送按钮 | 点击 | 调用 /api/chat，SSE 流式渲染宠物回复；保存对话 | content, petState, history | 流式期间禁用 |
| 顶部导航项 | 点击 | 跳转对应页 | — | 首页/成长/日记 |
